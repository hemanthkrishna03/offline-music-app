To set the path git bash for the PWA app : cd ~/offline-music-app
To delete a song from app CMD: rm "songs/Raataan-Lambiyan.mp3"
To move song from one folder to clone repo song folder CMD: mv ~/Downloads/"Bugga_Chinnadana_Neekosam.mp3" ~/offline-music-app/songs/Bugga_Buggagili.mp3

To Run new songs in app:

All songs are moved from downloads to songs folder of PWA App(Clone Repo)
Check git status .
It shows not committed files
Run the command git add songs/
git status every file is in green colour represents tracked
git commit
git push

If You want to add more songs rather than one by one do the following steps
1. Place all new songs in a new folder and run the below cmd in cmd prompt make sure that having the path of that new folder while running the     cmd and the cmd is "dir /b > filenames.txt"
2. After running this cmd u will see a text file named "filenames.txt".
3. Next run the Python file named "SongFormat" and u will see a output file named "appjs_entries.txt" in the Convert_Songs in that you will        find the all new song code format that should be pasted in the "app.js" file in github.
